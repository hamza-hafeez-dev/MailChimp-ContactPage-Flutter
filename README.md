# 📩 Mailchimp Contact Sales UI — Flutter

A clean Flutter recreation of the **Mailchimp Contact Sales** webpage UI.

I built this project to practice turning a real-world web design into a Flutter interface while focusing on clean layouts, form components, spacing, typography, and responsive UI structure.

> ⚠️ **Note:** This is an independent UI recreation created for learning and portfolio purposes. It is not an official Mailchimp application.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hamza-hafeez-dev/mailchimp-contact-sales-ui.git
```

### 2. Open the project

Open the project in **Android Studio** or **VS Code**.

### 3. Get dependencies

```bash
flutter pub get
```

### 4. Run the project

```bash
flutter run
```
